# 基于RTOS的超声信标定位系统

2025 年 TI 杯全国大学生电子设计竞赛 **J 题** 实现思路。

系统用基于FREERTOS操作系统stm32f103zet6实现

---

## 一、实现思路

**用旋转扫描代替阵列测距**：

1. 步进电机每次转 15°，把超声波模块依次指向 7 个方向
2. 每个方向上测一次到信标的距离
3. 只有正对信标的方向回波最强、距离最短、读数最稳定
4. 用距离值反查「列号」，用角度序号得到「行号」，两者拼成坐标

坐标编码：

```
site = (pass - 1) * 10 + range
```

- `pass` — 扫描角度序号（1~7），对应行 A~G
- `range` — 距离反查出的列号（模式 1 为 1~6，模式 2 为 7~10）

例：`pass = 3, range = 4 → site = 24 → C4`

## 三、步进电机驱动

### 步距与脉冲换算

| 参数 | 值 |
|---|---|
| 步距角 | 1.8° |
| 细分倍数 | 16 |
| 每圈脉冲 | 3200（= 360 ÷ 1.8 × 16） |
| 每度脉冲 | 8.889 |

`Stepper_AngleToPulses()` 负责角度换算脉冲数，支持小数角度（如 37.5° → 333 个脉冲）。

### 梯形加减速

如果一上来就按最高频率发脉冲，电机会「丢步」——原地嗡嗡响但不转。所以用梯形加减速：

```
速度
 ↑        ┌──────────────┐
 │       /                \
 │      /                  \
 └─────┴──────────────────┴────→ 脉冲序号
      加速      匀速        减速
```

`Stepper_CalcDelay()` 把总脉冲分成三段，返回每个脉冲对应的**半脉冲延时**（毫秒）：

- 加速段：延时从 4ms 线性降到 1ms
- 匀速段：固定 1ms
- 减速段：从 1ms 线性升回 4ms

一个完整脉冲 = 高电平延时 + 低电平延时，所以实际脉冲频率范围是 **125Hz ~ 500Hz**。

加速段长度由 `STEP_ACCEL_PULSES` 决定（默认 30 个脉冲）。总脉冲数不足 60 时按 1/3 分配，避免小角度转动时没有匀速段。

## 四、控制流程

### 命令来源

所有动作由 **TJC 串口屏**下发。屏上按钮按下后，通过 UART4 发 3 字节帧：

```
0xFF | CMD | 0xFE
```

UART4 中断里直接解析出 `g_uart4_cmd`，扫描任务轮询消费。

### 一次扫描的完整过程

**阶段 1：粗扫**

1. 收到 `0xFF 0x01 0xFE` 开始
2. 从 pass = 1 起，每个角度读 3 次距离
3. 有回波 → 记录该 pass，继续下一个角度
4. 连续无回波 → 停止扫描

**阶段 2：按回波数量选策略**

| 有回波的角度数 | 策略 |
|---|---|
| 0 个 | 强制输出最近的区间坐标 |
| 1 个 | 在该角度连采 15 次，投票确定列号 |
| 2 个 | 比较两个角度读数的极差，取更稳定的 |
| 3 个及以上 | 只采中间那个角度 |

### 测距数据怎么判稳

超声波单次读数会跳，代码用 **8 点滑动窗口**：

```c
if ((vmax - vmin) <= ALIGN_THRESH)        // ALIGN_THRESH = 20mm
    g_distance_mm = sum / SAMPLE_COUNT;   // 稳定，取平均
else
    g_distance_valid = 0;                 // 抖动太大，判无效
```

只有窗口内 8 个样本的极差 ≤ 20mm 才算有效，能滤掉多径反射和空气扰动造成的野值。主循环里读到 `g_distance_valid == 0` 就一直等到超时。

### 校准

屏上点「校准」进入校准模式，逐个格子采样 10 次取平均，把实测距离写进 `g_cal_val[]`。校准完成后 `g_calibrated = 1`，之后改用实测值查表。

支持两套：模式 1 对应列 1~6，模式 2 对应列 7~10。

## 五、通信协议

### 串口屏（UART4，115200）

**下行**（屏 → MCU）：3 字节 `0xFF | CMD | 0xFE`
**上行**（MCU → 屏）：TJC 的 ASCII 指令，如 `n0.val=1234`、`t7.txt="C4"`

| CMD | 功能 |
|---|---|
| 0x01 | 模式 1 开始扫描 |
| 0x02 | 模式 2 开始扫描 |
| 0x03 | 复位 / 清除 |
| 0x05 | 模式 1 进入校准 |
| 0x06 | 模式 2 进入校准 |
| 0x11 ~ 0x16 | 模式 1 校准值 1~6 |
| 0x20 | 模式 1 确认 |
| 0x21 ~ 0x24 | 模式 2 校准值 1~4 |
| 0x30 | 模式 2 确认 |
| 0x31 | 模式 2 完成 |

## 六、FreeRTOS 任务划分

| 任务 | 优先级 | 栈 (words) | 职责 |
|---|---|---|---|
| `RecvMsg` | 4 | 256 | USART3 收帧、XOR 校验、8 点滑动窗口滤波 |
| `SCAN` | 3 | 512 | 扫描、测距、校准、坐标解算（核心任务） |
| `TIME` | 3 | 256 | CPU 占用率统计，每 5 秒打印一次 |
| `TASK_KEY` | 2 | 128 | 4 个按键扫描，10ms 周期 |
